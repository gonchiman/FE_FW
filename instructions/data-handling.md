# データの取り扱い

ゲームデータを追加・更新するとき、またはデータ変換・計算を実装するときに適用する。

- データの出典、取得日、元データや対象ゲームのバージョンを記録する。バージョンが分からない場合は不明と記載する。
- 未確認の値と、確認済みの `0`・「なし」を区別する。欠損を自動的に `0` として計算しない。
- 仮の値や推測は、その状態が判別できるように管理し、確定データとして表示・計算に使わない。
- 出典から得たデータと、表示用の変換・計算ロジックを分離する。元の値と変換後の値の対応を追えるようにする。
- 計算の前提と必要な入力を明確にする。未確認の入力がある場合は、確定した計算結果として扱わない。
