# 開発の基本方針

このプロジェクトの作業開始時に適用する。

## 構成と実行

- React・TypeScript・Vite を使用する。Node.js は 24 系を基準にする。
- リポジトリのルートで `npm ci` を実行して依存関係を揃える。
- 開発サーバーは `npm run dev`、本番ビルドは `npm run build`、ビルド結果のローカル確認は `npm run preview` を使用する。
- GitHub Pages のプロジェクトパスに合わせて Vite の `base` を `/FE_FW/` とする。リンクやアセットの参照はこのパスで動作するように扱う。

## 初期構成と検証

- 初期構成はアプリの土台のみとし、ゲームデータや攻略機能は空に保つ。機能やデータは依頼された範囲で追加する。
- 未実装の機能や未確認のデータを、利用可能・確認済みと記載しない。
- アプリのコードやビルド設定を変更した場合は `npm run build` を確認する。
- 計算やデータ変換などのロジックを追加・変更した場合は、入力条件と期待する振る舞いに応じてテストを追加・実行する。単純な文言や設定の変更だけでテストを増やさない。
