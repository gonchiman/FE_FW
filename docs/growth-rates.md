# 成長率ページ

## 範囲と画面

`/FE_FW/#/growth-rates` に個人成長率を表示する。ホームは従来どおり本文が空のページ。
兵種補正や育成予測は含まない。

- 既存の `AppShell` とナビゲーションを利用する。
- キャラ名・スキル名・効果で検索し、名前・各能力値の見出しで昇順／降順を切り替える。能力値は最初に降順、名前は最初に昇順。
- 確認済みの日本語名を表示し、名前順は表示名で並べ替える。日本語名が未確認、または名前対応データを読み込めない場合は元の英語名を表示する。
- 日本語・英語の両方で検索でき、全半角・大小文字・ひらがな／カタカナを共通化する。
- 未確認値は `null` のまま保持して「—」と表示し、並べ替えでは常に末尾へ置く。`0` は数値として扱う。同値では名前・ID順で結果を安定させる。
- スマートフォンでは名前列を固定し、表の中だけ横スクロールする。表はキーボードでもフォーカスできる。
- 出典情報は初期状態で閉じた「データの出典」に表示する。

## 個人スキル・固有習得スキル

キャラ名の右に「個人スキル」「固有習得スキル」の2列を表示する。
セルには名称を1行で表示し、固有習得スキルが複数ある場合は最初の名称と「ほかN件」を表示する。
表の行高は48pxを維持し、数字列の幅を狭めずに表内を横スクロールする。
名称ボタンから既存の `Modal` を使った詳細を開き、そのキャラの同じ区分の全スキル・習得Lv・条件・効果を確認できる。
Esc・閉じるボタン・背景クリックで閉じ、元の名称ボタンにフォーカスを戻す。

検索には日本語名・確認できた英語名・効果・習得条件を使い、セルに出ていない強化版も対象にする。
スキルが未収録の場合は「—」を表示し、「持っていない」とは判定しない。
未確認の習得Lvや効果も `null` として保持する。習得Lvが未確認の固有スキルは詳細で「未確認」と表示する。
スキルデータだけの読み込みエラーでは、成長率表を残してエラーを表示する。

スキルは成長率とは別の [character-skills.json](../src/data/character-skills.json) に保存し、キャラクターIDで関連付ける。
型は [character-skills.ts](../src/types/character-skills.ts)、検証・グループ化・検索用テキストは [lib/character-skills.ts](../src/lib/character-skills.ts) に分離している。
各記録には安定したスキルID、キャラクターID、個人／固有習得の区分、名称、効果、習得Lv、条件、出典参照、確認状態を持たせる。
確認できた強化版は別の記録とし、`upgradesSkillId` で強化元を参照する。
この参照は置き換え関係だけを表し、効果によって別の個人スキルを強化する関係には使わない。
同じキャラの通常版・強化版を一覧に載せても、両方の効果が同時発動するとは扱わない。
将来の分析では、指定レベルで習得できる版や装備状態を選んで集計する必要がある。
現在は表示・検索までを対象にし、効果文から数値補正を自動計算しない。
血印・ブレイズアーツ・共通技能は今回の2区分に混ぜない。

入力スナップショットは [data/sources/character-skills.json](../data/sources/character-skills.json)、再生成は `npm run skills:import`、生成結果との一致確認は `npm run skills:check` を使う。
ゲーム内での照合は未実施であり、出典間で確認した名前・習得情報もゲーム内確認済みとはしない。

2026-10-01取得分は個人スキル62件、55人分の固有習得スキル106件を収録する。
日本語名を照合できた137件は日本語、未確認の31件は元の英語名で表示し、効果は出典の機能・数値・条件を保った日本語の要約とする。
固有習得のレベルはLv5が2件、Lv20が46件、Lv35が47件、不明が11件。
アスワン・セントリオン・キリーク・コウカ・ネイサン・タホウニア・トロイアの固有習得スキルは未収録であり、存在しないという確認ではない。
置き換え自体の根拠は今回確認できていないため、現在の `upgradesSkillId` は全件 `null`。
「＋」を外して未確認の日本語名を作ったり、強化版の効果から通常版を逆算したりしない。
元データはFortunes-Weave-Helperの固定コミットにあるDB、日本語名・区分・習得情報はGame8とGameWithを参照し、採用に使ったページを記録する。
上流のDBでレベル習得に分類されていても、共通技能を固有習得に混ぜない。

### 固有習得スキルの収録状況

検索欄と成長率表の間に、初期状態では閉じた「固有習得スキルの収録状況」を置く。
arknights_2のMapDatabaseの「データの範囲」を参考に、薄い区切り線と控えめな文字で表示する。
収録のある人数・レコード数、存在確認済みの未収録スキル、有無未確認のキャラ、習得Lv・日本語名・ゲーム内照合の確認状況を参照できる。
件数は検索結果ではなく全キャラと現在のスキルデータから計算し、個人スキルを含めない。強化版は別件として数える。

調査記録は [unique-skill-research.ts](../src/data/unique-skill-research.ts)、集計は [unique-skill-coverage.ts](../src/lib/unique-skill-coverage.ts)、表示は [CharacterSkillCoverage.tsx](../src/components/CharacterSkillCoverage.tsx) に分離する。
2026-10-01に未収録だった7人を調査し、コウカのAmplify Magic / Amplify Magic+、トロイアのModified Weapon / Modified Weapon+はLv50 / Lv60の掲載を確認したが、詳細表示用データにはまだ収録していない。
残る5人は有無未確認を維持する。調査日と出典へのリンクを表示し、調査で得た情報をゲーム内照合済みとはしない。
今後レコードを追加すると、該当する英語名とキャラIDで照合して未収録一覧から外す。通常版だけの追加では強化版の未収録を残す。
収録ありを網羅済みとは扱わず、レコードがないキャラをスキルなしとは判定しない。

## データと表示の分離

型・能力キー・表示順の定義元は [growth.ts](../src/types/growth.ts)。
表示用JSONは [character-growths.json](../src/data/character-growths.json) で、Fortunes-Weave-Helper の公開JSONから取り込んだ62名・558値を収録する。元の英語名を保持し、画面では [character-names-data.ts](../src/data/character-names-data.ts) の確認済み日本語名をキャラクターIDで参照する。この名前対応は成長率分析ページと共用する。
ゲーム内の数値との照合は未実施のため、すべての行を `status: "unverified"` とする。全行が同じ状態の場合は表の上に「ゲーム内未照合」を表示する。

データには出典ID、URL、取得日、元データの版、ゲームの版、補足を保存する。
不明なメタデータは `null`。取得日はこのアプリがJSONを取得した日時で、元記事が調査・更新された日時ではない。
キャラクターは出典IDと確認状態（`sample` / `unverified` / `verified`）を持つ。
確認状態が混在する場合は未照合の行に「未照合」を表示する。仮データと他の状態が混在するときは、仮データの行にも状態を表示する。

取得元は [Rico0319/Fortunes-Weave-Helper の data/fwe.json](https://github.com/Rico0319/Fortunes-Weave-Helper/blob/29609cc76a0a79a86473ef1e0980771e94c97640/data/fwe.json)。元記事は [Game8 の成長率一覧](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/618974)。リポジトリの更新に追従せず、このコミットの内容を固定して利用している。対象ゲームのバージョンは不明。

成長率の取得元から `units` のキー、`name`、`growths` だけを抽出し、[入力スナップショット](../data/sources/fortunes-weave-growths.json) に保存している。この成長率スナップショットには原文説明・評価・兵種・個人スキルなどを含めない。
このスナップショットは上流のファイル全体ではなく、必要項目を変更せず抜き出したものである。`fileBlobSha` は上流のJSONファイル全体のGit blob SHAであり、この抽出ファイルのハッシュではない。
取得情報に、リポジトリ・コミット・元ファイルパス・上流のGit blob SHA・取得日時・出典URLを保存する。
元リポジトリには取得時点で明示的なライセンスを確認できていない。出典の記録は転載許諾や数値の正確性の確認を意味しない。

## 再生成と更新

`npm run data:import` が [取り込みスクリプト](../scripts/import-growths.ts) を実行し、入力スナップショットから表示用JSONを生成する。`npm run data:check` は生成結果との一致だけを検証し、ファイルを書き換えない。
変換処理は [import-growths.ts](../scripts/lib/import-growths.ts)。キー名で能力値を対応付けるため、元JSONの `Spd` と `Dex` などの並び順が表示順と違っても取り違えない。数値の補正・推測・兵種加算は行わない。
元の成長率の明示的な `null` と `0` を区別し、欠落した項目・不正な値・衝突するIDはエラーにする。読み取り・変換が完了してから出力する。
上流を更新する際はコミットを選んでJSONを取得し、必要項目と取得情報をスナップショットへ更新してから再生成する。表示用JSONだけを手編集しない。
欠損は `null`、未照合の数値は `unverified` として扱い、確認済みに自動変更しない。

[growth-data.ts](../src/data/growth-data.ts) が入力を検証する。
形の不一致、ID重複、存在しない出典参照、不正な成長率などがあれば、表を表示せず読み込みエラーを出す。
表示用の検索・並べ替えは [lib/growth.ts](../src/lib/growth.ts) にあり、元データを変更しない。

## 共通テーブルの基準

[DataTable.css](../src/components/DataTable.css) を共通の定義元とし、外枠・縦横罫線には `--border` を使う。
ヘッダーは `--surface-hover`、数値は右揃え・等幅数字。並べ替えボタンには状態と次の操作を付ける。
名前列の幅・固定位置・未確認値の色は [GrowthRatesTable.css](../src/components/GrowthRatesTable.css) に分離している。
現在の適用先は [GrowthRatesTable.tsx](../src/components/GrowthRatesTable.tsx)、[NameMappingsTable.tsx](../src/components/NameMappingsTable.tsx)、[GrowthAnalysisPage.tsx](../src/pages/GrowthAnalysisPage.tsx) の表。
今後の表はこの共通スタイルを読み込み、可変のデータ・列・並べ替え状態を用途に応じて渡す。

## 確認と見本の更新

`npm test` でデータ検証・検索・欠損値を含む並べ替え・ルート解決を確認し、`npm run build` で型チェックと本番ビルドを確認する。
`npm run dev` の `/FE_FW/#/growth-rates` が実装から再生成する表示見本となる。
データを変更する場合は入力スナップショットと対応する検証を更新して再生成し、PC・390px・320px幅で表示を確認する。
表示件数、検索結果なし、列の昇降順、横スクロール、サイドバー遷移、戻る操作、本文スキップリンクを確認する。
