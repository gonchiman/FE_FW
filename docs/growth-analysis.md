# 成長率の統計分析

サイドバーの「成長率分析」、または `/FE_FW/#/analysis/growth-rates` から開く。
既存の `src/data/character-growths.json` を成長率一覧と共用し、新しいゲームデータは追加しない。
グラフはヒストグラムのみ。累積分布、箱ひげ図、散布図は実装していない。

## 画面と操作

- 9能力の選択を統計サマリー、グラフ、キャラクター一覧で共有する。初期選択は速さ。
- 数値条件を1件設定できる。能力・下限または上限・数値を指定し、等号を含めて対象を絞る。
- 数値条件は選択中の分析能力と異なる能力にも設定できる。空欄、負値、有限数でない入力はエラーを表示して結果を隠す。
- 階級幅は5・10パーセントポイント。縦軸は人数・割合。平均・中央値の基準線を個別に切り替える。
- 「割合を表示」「階級の範囲を表示」を個別に切り替える。どちらも初期状態はオフ。割合は有効データの人数を分母に、小数第1位まで棒の上に表示する。0件の階級は0.0%、0より大きく0.1%未満は `<0.1%` とする。階級を選択しても割合の分母は変わらない。
- 階級の範囲は各棒の下に「35〜」「40」の2行で表示し、通常の横軸の数字と切り替える。下端を含み上端を含まない。全文字が収まらない幅では通常の目盛りに戻す。割合ラベルは棒・隣接ラベル・基準線との重なりを避け、必要に応じて上の余白と引出線を設ける。
- 「画像を保存」でファイル名・縦横比・プレビューを確認してPNGを保存する。能力・数値条件・階級幅・縦軸・基準線・割合・階級範囲・選択階級を反映する。0件では保存できない。
- 保存画像はArknights_2の共通フレームに合わせ、白背景、中央のタイトル、左右の出典・条件、下部の横軸名を配置する。基準は幅960 CSS pxの2倍出力で、折り返しとラベルに必要な高さを確保する。縦横比は画像全体に適用する。対応ブラウザーでは保存先を選び、それ以外ではブラウザーのダウンロード設定に従う。
- 棒または度数分布表の階級を選ぶと、該当キャラクターの一覧を表示する。選択はサマリーや割合の分母に影響しない。
- 一覧は選択中の能力の降順。同値は英語名・IDで並べ、先頭10人と全件表示を切り替えられる。
- 能力、数値条件、階級幅を変更すると選択範囲を解除する。縦軸・基準線・割合表示・階級範囲の変更では選択を維持する。
- 棒はクリック・タップ・Enter・Spaceに対応し、同じ操作を罫線付きの度数分布表でも行える。
- 既存サイドバーの1140px以下でのメニュー表示を継承する。狭い画面ではサマリーを2列にし、表だけを横にスクロールする。

## 集計規約

1人を1件として同じ重みで扱う。`sample` は除外し、`unverified` は未照合の状態を明示して集計する。
能力ごとに `null` を除外して有効人数と欠損人数を表示し、0は有効値として含める。
数値条件で使う能力が欠損している人は、その条件を満たすと判定しない。

- 平均：有効値の合計 / 有効人数。
- 四分位数・中央値：昇順の位置 `(n - 1)p` を線形補間する。
- 標準偏差：表示対象の集団の記述統計として、分母を `n` とする。
- 四分位範囲：第3四分位数 − 第1四分位数。
- 0件では代表値を `null` / `—` とし、1件では標準偏差と四分位範囲を0とする。
- 区間は `[下端, 上端)`。全対象・9能力の最大値より大きい階級境界を軸の上限にする。100超を切り捨てない。
- 軸の範囲は能力や条件による絞り込みに影響されない。階級幅を変更した場合のみ境界を再計算する。
- 横軸の数字は5・10・20・50…ポイントの等間隔にし、画面幅に応じて間隔を選ぶ。数字のない階級境界には短い補助目盛りを付ける。端点を追加して間隔を不規則にしない。
- 割合の分母は、条件適用後の選択能力の有効人数。平均との差も同じ集団の平均を使う。
- 表示時のみ小数第1位へ丸め、計算は丸め前の値で行う。成長率は%、差・標準偏差はptで表示する。

未照合の出典値の統計であり、兵種補正、育成後の能力値、キャラクターの総合的な強さを表すものではない。
出典・取得日時・元データの版・ゲーム版は既存データから表示する。

## 実装と確認

- `src/lib/growth-statistics.ts`：条件抽出、記述統計、共通軸、階級の集計。
- `src/components/GrowthHistogram.tsx`：SVGによる描画、選択、アクセシビリティ。
- `src/components/GrowthHistogramImage.tsx`：保存プレビューとPNGで共用するヒストグラム。
- `src/components/ChartImageFrame.tsx` / `ChartImageSaveDialog.tsx` / `saveComparisonChartImage.tsx`：画像配置、保存画面、PNGへの変換。
- `src/pages/GrowthAnalysisPage.tsx`：状態とサマリー・グラフ・一覧の連動。
- `tests/growth-statistics.test.ts`：空集合、1件、同値、欠損と0、区間境界、100超、件数保存、元データの非破壊。

`npm test`、`npm run data:check`、`npm run build` で確認する。
画面では能力・階級幅・縦軸・基準線、条件の0件と不正入力、階級選択と解除、モバイル幅、キーボード操作を確認する。
画像保存では、ダウンロードしたPNGを開き、文字・目盛・棒・基準線・割合・階級範囲・選択範囲・条件・出典がプレビューと一致すること、スマートフォン幅でも画像が欠けないことを確認する。
