# 名前対応表

## 表示と操作

- サイドバーの「名前対応表」から `/FE_FW/#/character-names` を開く。従来のURLはキャラクタータブを初期表示する。
- 「キャラクター／クラス」で切り替える。クラスへの直接リンクは `/FE_FW/#/character-names?tab=classes`。再読み込みと戻る／進むでもURLに対応するタブを表示する。未知のタブ指定はキャラクターに戻す。
- 成長率データのキャラクターID・英語名、または固定版のクラス名簿を基準に全件を表示する。
- 日本語名・英語名・確認状況・出典の4列。日本語名が未確認の場合は `—` と表示する。
- 日本語・英語の部分一致検索に対応する。全角・半角、英字の大小文字、ひらがな・カタカナの違いは吸収する。
- 確認済／未確認で絞り込める。右上の件数は絞り込み結果、表の下の確認済件数は全体を示す。単位はキャラクターが人、クラスが件。
- 検索・絞り込み・並べ替え・出典展開は、タブ間の切り替えでは各タブごとに保持する。ページを離れると初期化する。
- 初期順序は日本語名の昇順。日本語・英語の列見出しで昇順／降順を切り替え、未確認の日本語名はどちらの向きでも最後に置く。
- 確認済の行の「出典」で、その行の直下に参照ページ、取得日、元ページの版、ゲームの版、確認日、照合内容を開く。
- 出典は各タブで一度に1件を開く。検索、絞り込み、並べ替えを変更すると閉じる。「閉じる」または表内のEscape操作後は対応する「出典」ボタンにフォーカスを戻す。
- タブは左右矢印・Home・Endでも切り替えられる。非選択側の表や入力はフォーカス移動・読み上げの対象にしない。
- 狭い画面では表を横スクロールする。共通サイドバーの切替幅をそのまま使用する。

表の外枠・縦横罫線・見出し・セルの余白は既存の `DataTable.css` を使用する。共通部品は [NameMappingsTable.tsx](../src/components/NameMappingsTable.tsx) と [NameMappingsTable.css](../src/components/NameMappingsTable.css)。名簿・出典・対象種別・並べ替え・展開状態を渡し、名前列や出典欄の表示を共通化する。出典はキーボードでも開閉でき、外部の参照ページは新しいタブで開く。

## 名前データ

`src/data/character-names.json` に `sources` と `mappings` を保存する。共通の検証・関連付け・検索・ソートは [name-mappings.ts](../src/lib/name-mappings.ts)、共有型は [name-mappings.ts](../src/types/name-mappings.ts) に置く。`src/lib/character-names.ts` は既存のキャラクター向けAPIを維持する。

- `sources`：出典ID、言語、名称、URL、取得日、元ページの版、ゲームの版。版が不明の場合は `null`。
- `mappings`：キャラクターID、日本語名、確認状況、出典IDの配列、確認日、照合内容。
- キャラクターIDは成長率データのIDをそのまま使用する。英語名は元データから参照し、ページごとに別の名簿を作らない。
- 対応が未登録のキャラクターは、日本語名 `null`・確認状況 `unverified` として一覧に残す。
- 確認済の登録には日本語名、日本語と英語の出典、確認日が必要。名前や人物紹介で同一人物と確認できた根拠を `note` に記録する。
- 名前の確認状況は成長率の数値の確認状況とは独立している。名前が確認済でも、成長率が検証済みであることを意味しない。
- 名前データの更新で、成長率ページの表示名や成長率データを変更しない。他ページで日本語名を使う際はこの対応表を共通利用する。

2026-09-30時点で、成長率データに収録している62名すべての日本語名を登録している。最初の4名に58名を追加し、次の根拠で対応を確認した。

- カイ / Cai、ディートリヒ / Dietrich、セオドラ / Theodora、レダ / Leda は任天堂の日英人物紹介、イシュマール / Eshmel は同一の開発者インタビューの日英版で照合した。
- FEファンサイトの人物ページにある「名前」「英語名」欄、またはGamerSkyの記事の日英併記で対応を確認した。任天堂の日本語人物紹介に掲載されている名前は、公式表記も照合した。
- 日英名の併記が確認できない人物は、Nintendo DREAM WEBの公式紹介の引用とSerenes Forestの人物紹介を、声優・所属・人物像で照合した。Game8とNintendo Insiderの人物紹介も一部の補助資料に使用した。
- 非公式資料は出典名で明示する。「確認済」は資料上で名前の対応を確認した状態であり、すべてが公式の日英対照表やゲーム内データによる確認ではない。

氏名の表記と照合内容だけを記録し、人物紹介の本文や画像は取り込まない。ブラウザから公式ページや外部サービスへ自動問い合わせを行わず、表示・検索はローカルのデータで完結する。

## クラス名の対応

- [fortunes-weave-classes.json](../data/sources/fortunes-weave-classes.json) は、キャラクターと同じ上流コミット `29609cc76a0a79a86473ef1e0980771e94c97640` から抽出した59クラスの名簿。英語JSONのキーをID・英語名とし、区分と出典情報を保持する。
- [class-names.json](../src/data/class-names.json) の `mappings` は `classId`、日本語名、確認状況、出典、確認日、照合根拠を持つ。キャラクターの成長率とは独立して読み込む。
- 日本語の兵種一覧と、名称・区分・成長率補正を照らして対応を確認する。数値が異なる兵種は、日英の必要技能・スキル・解放条件も確認し、その根拠と数値の相違を各行の出典欄に記録する。
- 主な資料は [GameWithの日本語兵種一覧](https://gamewith.jp/fefw/573025)、[Game8の英語兵種一覧](https://game8.co/games/Fire-Emblem-Fortunes-Weave/archives/620256)。非公式資料に基づく名前の確認であり、ゲーム内の成長率が検証済みであることは意味しない。
- `Commoner` は平民として扱う。日本語資料にある貴族は上流の固定JSONに `Noble` がないため、この59件へ推測で追加しない。
- 対応未登録のクラスも一覧から落とさず、日本語名・確認日を `null`、状態を `unverified` とする。確認済の名前には空でない照合根拠と日英両方をカバーする出典が必要。
- 成長率の数値は名簿へ取り込まない。兵種補正の計算や成長率ページへの適用は、この名前対応機能には含まない。

## 更新手順と確認

1. 既存キャラクターIDに対応する日英の名前と人物紹介を出典で確認する。
2. JSONに出典情報と対応を追加し、取得日・確認日を記録する。未確認の名前を推測で補完しない。
3. `npm test` で、IDと出典の参照、重複、日付、確認済の成立条件、検索・並べ替え・絞り込みを確認する。
4. `npm run data:check` と `npm run build` を実行する。
5. 名前対応ページで登録内容・出典を確認し、狭い画面、検索0件、メニューからの移動も確認する。

クラス名の更新は固定版の名簿と照合資料を確認してから対応データを編集する。59件全体の保持、出典の整合性、誤ったクラスID・重複・欠損・根拠のない確認済登録の拒否もテストで確認する。

画面の確認用見本は、両タブの実装から表示する。`npm run dev` で上記の2つのURLを開き、日英検索・並べ替え・確認状況・出典開閉、タブごとの条件保持、直接リンク・再読み込み・戻る／進むを確認する。PCと390px・320px幅で、表だけが横スクロールし本文全体がはみ出さないことを確認する。

全62名への関連付け、日英で表記が大きく異なる名前と取り違えやすい名前もテスト対象に含む。名簿や確認済の登録数を意図的に変更した場合は、テストの期待値も根拠に沿って更新する。
