# クラス情報ページ

## 画面と範囲

- 一覧は `/FE_FW/#/classes`。クラス名のリンクから `/FE_FW/#/classes/<URLエンコードした元のID>` へ移動する。
- 日本語・英語で検索し、区分で絞り込む。基本情報・能力補正・成長率補正を切り替えて比較する。
- 名前・区分・移動・各能力値を並べ替える。未収録値は昇順・降順とも末尾に置き、0と負数は数値として扱う。
- 日本語名は既存の確認済み対応表を使う。未確認の場合は元の英語名へフォールバックする。
- 詳細に基本情報、9能力の補正、9能力の成長率補正、兵種スキル、マスタースキルを表示する。成長率補正は加算値（pt）で、個人成長率に合算しない。
- 一覧と詳細の往復では検索条件・表示項目・並び順・スクロール位置を維持する。詳細URLを直接開くこともできる。
- `DataTable.css` の罫線・配色・数値配置を利用する。クラス表の行高は通常40px、狭い画面とタッチ操作では44px以上。名前列を固定し、表内を横スクロールする。
- 詳細のパネルは既存の `CollapsibleAnalysisPanel` を利用する。新しい計算機やグラフは含めない。

一覧から独立した詳細ページへ移動する構成は、arknights_2の `OperatorDatabase` / `OperatorDetailPage` / `OperatorDetailLink` を参考にした。2026年9月の一覧・詳細画面の更新を確認し、古い詳細モーダルではなく詳細ページの構成を採用した。

## データの扱い

取得元は [Fortunes-Weave-Helperの固定版](https://github.com/Rico0319/Fortunes-Weave-Helper/tree/29609cc76a0a79a86473ef1e0980771e94c97640/data)。コミット `29609cc76a0a79a86473ef1e0980771e94c97640` の `fwe.json` と `fwe.db` を使う。取得日、ファイルのSHA-256、元データの版を入力スナップショットに記録する。ゲームの版は不明、ゲーム内の数値・効果との照合は未実施。

- JSONの59クラスを名簿・区分・成長率の基準とし、DBの58クラスを関連付ける。共通クラスの成長率は照合し、不一致をエラーにする。
- 平民（Commoner）はDBに詳細がないため、JSONにある成長率のみ保持し、能力補正などは `null` にする。
- 兵種スキルは元の表の全行を保持する。DBの単一 `class_ability` 欄のみでは複数スキルが欠落するため使わない。
- 未収録の対応武器・スキル・効果と、明示された0・なしを区別する。Warriorのマスタースキル効果 `TBD` は未確認として扱う。原文は入力スナップショットに残す。
- 数値はキーで対応付け、技と速さなどの列順に依存しない。負の補正もそのまま保持する。
- 既存の名前対応表に記録された日英資料の差異を出典欄で参照できるようにする。日本語名の確認済み状態を数値の確認済み状態と取り違えない。
- スキル名・効果は出典の英語表記を保持する。元の値、表示用の変換、検索・並べ替えは分離する。

## 再生成と確認

`npm run data:import:classes` で入力スナップショットからアプリ用JSONを再生成する。`npm run data:check:classes` は生成結果との一致を確認する。通常の `npm run data:check` でも個人成長率とクラス情報を両方確認する。再生成と画面表示に外部通信は不要。

更新時は固定するコミット・取得元ハッシュ・抽出元の行をまとめて更新し、表示用JSONだけを手編集しない。
`npm test` で変換・欠損・複数スキル・検索・並べ替え・ルートを、`npm run build` で型と本番ビルドを確認する。
画面では一覧と詳細の往復、直接URL、検索結果なし、マイナス値・未収録値、スマートフォン幅の横スクロールを確認する。
